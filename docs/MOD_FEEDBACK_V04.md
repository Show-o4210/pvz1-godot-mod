# mod-v0.4.0-local：实际试玩反馈修正

2026-10-06。仅本地开发；不上传 GitHub，不修改固定还原仓库或覆盖历史归档。素材仍来自 PVZ 汉化2版（1.0.0.1051 CN V2）。

以上为 v0.4 阶段记录。后续 v0.5 按用户新授权同步 GitHub，并将画面改为 900×640、顶部预留缩为 40 像素；最新布局与阳光循环见 [LAYOUT_AND_SUN.md](LAYOUT_AND_SUN.md)，旧阶段完整包不覆盖。

## 军帽盖住啃食僵尸

原因是帽子挂在植物的动画脸部下，继承父节点层级，再叠加相对 z=5；同排植物根节点为 100+行号×10，僵尸为该值+2。因此帽子的有效层级超过了僵尸。

帽子现在只加 +1，仍盖住植物脸部，但由同排僵尸正常遮挡。保留完整头部变换绑定和受击材质，不能为了层级正确而把配饰从头部拆出来。

可复用方法：先列出父子节点累加后的有效 z，再对照同排其他实体。用实际纹理交叠做 GPU 验证，不能只检查某个节点的局部数字。本次三档军帽分别与 260、278、246 个不透明僵尸像素交叠，均正确遮挡。半透明贴图边缘允许一个 8 位颜色量化步长，避免把合法透明混合当成层级错误。

入口：`scripts/rank_hat.gd`、`tests/hat_occlusion_test.gd`。

## 卡槽遮挡第一排

本地原始白天背景是 1400×600；当前游戏使用其中 800×600 区域。单纯纵向拉伸会改变草坪格子比例，换全景也需要重新对齐格子。本版采用独立顶部工具区，不需要下载替代背景：

- 逻辑画面由 800×600 扩为 800×690。
- 种子栏、铲子、控制提示和菜单放在顶部 90 像素区域。
- 游戏世界根节点整体下移 90 像素，背景保持原比例，格子、角色、推车使用原局部坐标。
- 底部文字和波次条随草坪下移，菜单及结算面板随之调整。
- 移除上版第一排植物下移 14 像素、帽子局部下移 7 像素、充能条改在脚边及隐藏生产条的特例。

这里扩大的是可见画面和 UI 空间，没有生成或拉伸新的草坪纹理。第一排三档向日葵军帽在充能放大时的边界仍完全位于工具区下方，充能与生产反馈可以同时显示。

根节点有偏移之后，必须明确区分局部、世界和 HUD 坐标：

| 路径 | 转换方式 |
| --- | --- |
| 鼠标位置 → 草坪格子 | 输入视口位置经根节点逆变换；基础场景使用 `to_local(get_global_mouse_position())` |
| 动画枪口 → 世界内子弹 | 枪口给出世界位置，用根节点 `to_local()` 转回子弹的父节点局部位置 |
| 僵尸断手/掉头 → 世界内特效 | 动画部件 `to_global()` 后，再用游戏根节点 `to_local()` |
| 阳光 → 顶部 HUD | 保留当前世界位置后换父节点，目标用 HUD 槽位坐标 |

只改点击坐标是不够的，容易出现“能种植，但豌豆、断肢或阳光偏了 90 像素”。专项检查覆盖这些实体的起点和终点。

入口：`scripts/mod_game.gd`、`scripts/game.gd`、`tests/mod_mouse_render_test.gd`、`tests/feedback_wave_test.gd`。

## 工具取消、铲除和吞咽音效

先核对社区原版动作对应关系，再使用本地原版 Ogg；没有用名称猜测音效用途。

| 动作 | 本版对应原版声音 |
| --- | --- |
| 拾起植物卡 | `seedlift.ogg` |
| 拾起铲子 | `shovel.ogg` |
| 实际铲除植物 | `plant2.ogg` |
| 取消卡片/铲子、铲空格 | `tap2.ogg` |
| 僵尸吃完一株植物 | `gulp.ogg` |

取消入口单独为 `cancel_selection()`。右键、重复点击已选卡/铲子、Tab 切换时需要取消声；成功种植或铲除后由程序清空选择，不附加取消声。没有选择时右键不制造声音。吞咽只在植物生命值归零并移除时播放一次，普通连续啃食继续使用已有声音。

可复用方法：区分“用户取消”和“成功动作结束时清理状态”；记录实际调用的声音序列，检查不存在重复播放和错误附加音效。导入工具同步加入声音名单，保证重新导入后仍可用。

社区核对位置：[Board.cpp](https://github.com/ruslan831/PlantsVsZombies-decompilation/blob/master/Lawn/Board.cpp) 的 `MouseDownWithTool` 与铲子处理，[TodFoley.cpp](https://github.com/ruslan831/PlantsVsZombies-decompilation/blob/master/Sexy.TodLib/TodFoley.cpp) 的 `FOLEY_SHOVEL / FOLEY_USE_SHOVEL / FOLEY_DROP` 映射，[Zombie.cpp](https://github.com/ruslan831/PlantsVsZombies-decompilation/blob/master/Lawn/Zombie.cpp) 的植物吃完后 `SOUND_GULP`。

## 开场、第一波与最后一波

新 `scripts/level_cues.gd` 管理文字和原版声音：

| 时机 | 文字/行为 | 声音 |
| --- | --- | --- |
| 开场 3 秒 | 准备… → 开始… → 种植！ | `readysetplant` |
| 第一只计划僵尸入场 | 僵尸来了！ | `awooga` |
| 最后一波开始前 5 秒 | 一大波僵尸即将来袭！ | `hugewave` |
| 最后一波开始 | 最后一波！ | 独立声道 `siren` |
| 最后一波开始后 0.6 秒 | 保留波次提示 | `finalwave` |

时机取自现有关卡 schedule，不把当前最后一波的秒数写死。开场期间冻结战斗计时，之后保留原出怪时间；正常三波玩法多了 3 秒准备阶段。暂停冻结文字、计时与两个声音播放器，结算时清理。每个事件只触发一次。警报和语音使用两个播放器，避免最后一波语音打断警报。

这是当前测试关卡的波次提示实现，没有补全原版冒险关卡、旗帜僵尸或完整旗帜动画。参考 [Board.cpp](https://github.com/ruslan831/PlantsVsZombies-decompilation/blob/master/Lawn/Board.cpp) 的 `NextWaveComing` 和 [CutScene.cpp](https://github.com/ruslan831/PlantsVsZombies-decompilation/blob/master/Lawn/CutScene.cpp) 的 `ReadySetPlant`。仅核对行为，未复制社区 C++。

## 工作时间翻倍

`SUN_WINDOWS` 从 12/20/30 秒改为 24/40/60 秒，周围 Weak Work 也使用翻倍后的来源窗口。长按激活仍为 2.4 秒，自动生产间隔 8 秒、产量 25/30/35、邻株 75% 效率不变。刷新和升级保留生产进度，Stop 仍冻结进度；不会通过重新激活重置上一轮生产。

修改状态窗口时，需要同时更新恰好到期、跨越到期的大时间步和邻株降级测试，不能只改 UI 文案。测试使用正常经济的通关程序验证了 15/15 胜利，220.4 秒、147 次长按；操作程序的选择会受窗口改变影响，此结果不代表真人难度已经平衡。

## 验证与本地预览

330 项通过：基础 150、长按 43、工作与连锁 50、军帽反馈 30、真实鼠标/GPU 15、军帽遮挡/GPU 6、音效与波次 36。基础自动对照三波通关也通过。

音效专项用实际音频驱动运行。快速 headless 验证中的 Dummy 音频驱动不消费 Ogg 播放实例，退出时会出现资源引用警告；实际驱动运行结果没有此警告。预览由 Godot Movie Maker 捕获真实画面与混音，再转为 H.264/AAC；23.017 秒、800×690、60 FPS、48 kHz 双声道，音轨有非零声音。

`build/mod-v0.4.mp4` 展示开场、波次、工具取消/使用、吞咽、军帽遮挡和自主生产。录制脚本为 `tests/capture_feedback_mod.gd`：压缩波次时间、高起始阳光和演示植物额外生命值仅用于录制，不影响正常关卡。
