## 向日葵状态和计时

| 状态 | 如何进入 | 生产行为 |
| --- | --- | --- |
| Stop | 新种下或工作时间结束 | 不生产，冻结并保留当前生产进度 |
| Work | 自己完成一次长按 | 按自己军衔全额自动生产 |
| Weak Work | 周围八格的向日葵完成长按 | 按自己军衔的 75% 产量自动生产 |

长按完成只激活，不即时发钱。松开之后继续生产；持续长按可以再次完成激活。工作时间与生产倒计时是两个独立时钟：重新激活只将到期时间刷新到“当前时间 + 本阶时长”，不会重置生产倒计时，也不把剩余时长无限相加。

Stop → Work/Weak Work 恢复剩余生产时间，停工期间不累计欠账。Weak Work → Work、Work → Weak Work、多个邻株重复激活、同类叠加升级都保留同一个生产进度。暂停同时冻结两种时钟。Work 到期仍有邻接工作时间时，降为 Weak Work，否则 Stop。恰好在到期边界完成的一轮正常产出一次。

自己操作所得的全额到期时间和邻株赠送的弱工作到期时间分别保存，以防短暂 Work 将较长的 Weak Work 全部变成全额收益。邻接工作时长由激活主株军衔决定；产量则由每个邻株自己的军衔决定。自动产出不再激活其他植物，周围一圈不向第二圈传播。

邻株效率只降低产量，间隔不重复惩罚。小数余量逐株累计：一阶弱工作四份合计 75，三阶弱工作四份合计 105。阳光仍需点击收集，并沿已有动画飞回槽位。

脚边显示绿色 WORK、金色弱 WORK、灰色 STOP 和细生产进度条，原版植物贴图保持原色。顶部显示激活充能、下一份阳光的剩余时间和工作剩余时间。

## 豌豆联动

每一行保存共享联动能量。完成一次主动充能，一/二/三阶主株分别贡献 1/3、1/2、1 份能量，满一份时本行其余射手各射一次，主株不重复射击。六个整数单位表示一份能量，贡献分别为 2/3/6，避免浮点累计误差。

切换主株保留能量；混合等级超过一份的零头继续保留，例如 1/3 + 1/2 + 1/3 触发一次联动后剩 1/6。三阶贡献一整份，触发一轮并保留既有零头。自动射击、邻株联动、取消的长按均不贡献能量。升级不追溯改变已积累能量。同行只剩一株或空行时清零。

联动不跨行，不给忙于前摇的邻株叠加第二份射击。每株沿用自己的枪口、前摇、伤害和子弹大小。此版仅再增大二/三阶的子弹视觉尺寸，伤害沿用上版 20/24/28，避免同时过度增强。

## 军帽与可复用的表现处理

三档军帽采用内置 image_gen 生成，原始透明 PNG 保留在 `assets/mod/rank1.png`、`rank2.png`、`rank3.png`。软帽、星徽军帽、金色麦穗军帽分别对应三档。它们是本项目新增图像，和游戏原版素材同样暂留本地；完整阶段归档包含这三张图。源码里的帽子引用需要这组素材。

统一生成提示：一顶独立透明军帽，PVZ1 风格的明快手绘卡通，深棕轮廓、简单阴影、厚实可读形状，正面略朝右，底边近水平，橄榄绿与暖金色，约 38 像素宽时仍可辨认；不含植物、人头、文字、水印、背景及外投影。

三次提示的主体分别为：小型橄榄绿布制软帽、短帽檐和黄铜圆徽；橄榄绿军官大檐帽、深绿帽檐、单颗黄铜星徽和金边；橄榄绿高级军官帽、深绿帽檐、金色帽带和麦穗徽。输出原图不裁改像素，在 Godot 中通过 Sprite2D region 统一有效区域和显示宽度。

帽子挂在实际的脸部 Sprite 下：豌豆为 `HeadAttachment/anim_face`，向日葵为 `anim_idle`。继承完整仿射变换，随头身联动、射击、摇摆和根部放大移动；复用植物受击材质。只按世界位置复制坐标会遗漏旋转、缩放和倾斜，容易重现此前头身、眼皮不同步的问题。

mod-v0.3 曾通过第一排植物下移、长按条移到底部和隐藏生产条避让卡槽。mod-v0.4 用独立顶部工具区取代这些特例：画面 800×690，草坪整体下移 90 像素，恢复原植物落点、帽子贴合位置和头顶充能条，脚边生产反馈保持可见。固定格子的点击范围不随植物放大改变。帽子子节点相对 z 为 +1，处于植物脸部之上、同排僵尸 +2 之下。`build/.gdignore` 避免 Godot 导入预览帧和测试截图。

## 验证与试玩

- `tests/charged_actions_test.gd`：43 项长按、升级、收集、取消、暂停与对照模式检查。
- `tests/plant_network_test.gd`：50 项工作状态、生产进度保留、重叠/降级/到期边界、75% 余量和军衔能量检查。
- `tests/rank_presentation_test.gd`：30 项透明军帽、全变换绑定、射击/眨眼/受击和状态反馈检查。
- `tests/mod_mouse_render_test.gd`：15 项实际鼠标与 GPU 检查，含第一排三档军帽在充能放大时的边界。
- `tests/hat_occlusion_test.gd`：6 项三档军帽与啃食僵尸的真实 GPU 像素遮挡检查。
- `tests/feedback_wave_test.gd`：36 项原版声音解码、交互音效、坐标变换、开场/波次、暂停与结算检查。
- 基础回归 150 项。合计 330 项通过。正常经济、卡片冷却、一次只操控一株的三波检查击败 15/15 僵尸；通关 220.4 秒、147 次长按。

当前 23 秒含音效预览由 `tests/capture_feedback_mod.gd` 配合 Godot Movie Maker 生成，见 `build/mod-v0.4.mp4`。高初始阳光、压缩波次时间与防止演示植物死亡的生命值仅用于预览，不进入正常游戏。上版 `tests/capture_work_mod.gd` 及 24 秒预览在历史归档中保留。

试玩重点：工作期限是否需要更长、生产间隔是否还需放慢、一阶经济是否紧张，以及三阶主株带同行部队是否有明显价值。自动测试证明规则和流程可用，不代表真人平衡已确定。
