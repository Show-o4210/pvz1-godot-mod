# v1 · UI 与动画还原基线

素材来源版本：**PVZ 汉化2版（PVZ1 1.0.0.1051 CN V2）**。项目引擎：**Godot 4.7.2**。

这是进入 Mod 大改前保留的还原基线，尚未完整复刻原版冒险模式。包含白天 5×9 草坪、三种植物、普通/路障僵尸、阳光、飞行豌豆、啃食、铲子、推车、暂停与三波胜负。

v1 修正卡片尺寸、草坪坐标、角色落点，加入射击前摇、声音与命中反馈、植物闪白/坚果裂纹、断臂/掉头/倒地淡出。随后修复颜色变暗、豌豆头身联动、下巴缺失、僵尸步态和停走过渡，以及啃咬后行走的手部贴图残留。

验证结果：105 项检查通过；按正常经济与冷却规则自动完成三波关卡，击败 15/15 僵尸，模拟时间 188.2 秒。GPU 零效果颜色对照 RGBA 最大误差为零。全部问题与处理方式见 [ANIMATION_RENDERING.md](ANIMATION_RENDERING.md)。

GitHub 的源码与 Release ZIP **不包含原版素材**；克隆/下载后须按 [ASSETS.md](ASSETS.md) 从自己的 PVZ 汉化2版本地安装导入，再运行 Godot。原版资源、含资源的 v1 完整归档和全彩预览只保留在用户本地。

还原仓库：[Show-o4210/pvz1-godot-restoration](https://github.com/Show-o4210/pvz1-godot-restoration)。后续大改使用独立仓库：[Show-o4210/pvz1-godot-mod](https://github.com/Show-o4210/pvz1-godot-mod)，从同一 v1 Git 基线开始。

已知范围限制：三波测试关卡、简化掉落粒子、替代字体，背景音乐暂未接入；不含图鉴、存档、夜晚、泳池、屋顶或更多植物。
